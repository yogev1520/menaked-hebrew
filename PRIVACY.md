# Privacy — Preliminary Statement

[עברית – הצהרת פרטיות ראשונית](PRIVACY_HE.md)

**Status: planning-stage document. This is not a final privacy policy for a released product.**

Menaked is intended to add niqqud to Hebrew text on the web page the user chooses to process. The project aims to prioritize on-device processing and, if technically feasible, offline operation after any necessary model download.

These are goals under investigation, not verified guarantees.

## Questions still being evaluated

- Will the selected niqqud engine run entirely in the browser?
- Will any model or language data need to be downloaded, and when?
- Will any text ever be sent to a remote service?
- Will the extension store text, preferences, diagnostics, or usage data?
- What permissions will the extension require, and why?

No final decision has been made on these points. The project must not claim that page text never leaves the device until the implementation and its network behavior have been verified.

## Before an initial release

The project will document:
- What information is processed and for what purpose.
- Whether page text or other data is transmitted off-device.
- What is stored, where it is stored, and for how long.
- Required browser permissions and their purpose.
- How users can control processing and remove stored data.

A complete, implementation-specific privacy policy must be published before a public release.
