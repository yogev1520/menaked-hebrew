# Contributing

[עברית – הנחיות לתרומה](CONTRIBUTING_HE.md)

## Current status: external contributions are paused

Menaked is in a private-first development phase. The project is not currently accepting outside code contributions, pull requests, or community-maintained changes.

This policy is intentional: the initial architecture, Hebrew quality criteria, engine evaluation, privacy model, and cross-platform feasibility need to be established and validated before opening collaborative development.

The contribution process described below is preparatory guidance for a possible future phase. It does not mean that contributions are currently open.

## Future contribution areas

- Hebrew niqqud engine research and evaluation.
- Browser-extension architecture and prototypes.
- DOM safety, reversibility, and dynamic-page handling.
- Testing, accessibility, and browser compatibility.
- Hebrew and English documentation.

## Future pull request expectations

If and when external contributions are opened, contributors will be asked to:
- Keep changes focused and explain the problem they solve.
- Include tests or reproducible steps when applicable.
- Document limitations and known risks.
- Update both Hebrew and English documentation when changing project-level behavior or decisions.
- Avoid private data, credentials, and copyrighted datasets without appropriate rights.

## Project decisions

Technical choices are not final until they are discussed and documented. No particular model, framework, browser target, or license should be assumed selected unless the project documentation says so.

## Code of conduct

Be respectful, constructive, and welcoming. Critique ideas and implementations, not people.
